# 地面走路：准备、测量与结果

地面走路是独立模式，使用 `WalkingConfig`、`WalkingSession` 和
`WalkingProcessor`，沿用配置标识 `Sprint and Gait Test`。当前仅实现单人、单次、
单向通过，允许从任一端进入，不实现跑步和往返算法。

## 操作流程

1. 在手动配置选择 `Sprint and Gait Test`。结束方式可选 `Status change`
   （通过出口后自动结束）或 `Software command`（手动结束）。可指定第一只进入的
   脚 Left/Right，或保留 Not defined。
2. 进入测试准备页后保持设备空场。采集层识别完整帧的段数，连续接收 1000 个
   无遮挡、有效且无丢帧的样本后就绪。界面显示 N 段及标称 N 米。
3. 就绪期间持续采集，任何遮挡、无效光束、校验错误、缺段或序号异常都会撤销就绪。
   500 ms 未收到新样本也会撤销就绪。未收到完整数据时会显示连接检查提示。
4. 点击开始后等待走入，算法以首个有效接触的首帧为时间零点。确认接触的延迟不计入事件时间。
   点击时在处理帧的同一线程重新核查就绪状态，冻结 `PreparedDevice` 后才创建处理器。
   准备和正式测试使用同一个采集流，不在点击开始时重启设备。
5. 自动结束要求识别单向进展、入口和对侧出口附近的落脚位置，并连续空场 500 ms。
   入口/出口候选区宽度为 `min(0.6 m, 光束跨度的 40%)`，需要实机验证。
   结束确认时间不计入测量时长；在中间短暂无人遮挡不会自动结束，始终可以手动停止。

当前模块标称每段 1 米；自动识别段数不代表自动校准安装间距和物理排列。
距离使用 `DeviceLayout.positions_m`，可跨段接缝；排列与反向设置沿用采集接口。
数据流内布局锁定。准备阶段若更改段数或设备重启，返回配置重新连接以重新识别。

## 时间、接触与指标

设备采样率为 1000 Hz；时间来自解包后的设备序号，每样本间隔 1 ms，
与 USB 到达批次无关。红外遮挡是光学接触代理，不提供压力或横向坐标。

- 用连续遮挡及真实坐标形成接触区，允许跨段连续区域合并。
- 默认有效接触至少 60 ms，确认时回溯首帧。离地确认 10 ms，事件时间记录为最后
  一帧遮挡之后的首个缺席样本。短暂抖动不单独计步。
- 落脚位置取接触期间位置样本的中位数。步长是相邻有效落脚点距离，跨步长是同脚
  连续两次有效落脚点距离。接触内脚掌滚动不作为人体前进距离。
- 单/双支撑时间按完整同脚周期内的接触区间交集计算。入口周期可以与稳定行走周期不同。
- 整趟速度定义为首末落脚点位移 / 首次有效接触至最后遮挡结束的时长，包含停步。
  它不是人体质心速度，采集有缺口或首末接触不完整时留空。
- 连续可观测的接触中，至少 2 秒没有下一次落脚，标记为停步候选区间。
  保留它在整趟时长中的贡献，行走阶段指标排除与该区间相交的步/周期/接触。
- 行走速度为有效步长总和 / 对应步间时间总和；步频使用相同有效步间时间计算。
- 未指定起始脚时仅记录 A/B。遮挡合并、身份不明确或采集缺口后，建立新的身份段，
  不继续推断原左右脚。边缘、未闭合、过短或不确定的接触保留排除原因。
- 任何指标没有足够有效数据时使用 `None`，界面显示“数据不足”，不填零或插值。

## 异常处理

短暂丢帧、校验失败和不完整包允许继续采集，但使当前接触和跨缺口周期失效。
恢复首帧上已经存在的接触具有未知触地时间，需要排除；之后的新接触可独立计量。
异常前的未闭合接触不得无限延伸到后续片段。

布局变化、数据流变化、设备断连、序号倒退/重置、1 秒无数据会结束本次测试，
保留已得到的有效结果并标记中断。帧序号正常 uint32 回绕由采集层展开，不属于重启。
检测到反向行走也会中止单向测试。中断后重新识别、自检，再开始另一次测试。

## 数据与验证

报告保存本次配置、设备布局、采样率、自检上下文、接触/步/周期、停步候选和异常记录。
足迹回放支持全部段，未知脚使用中性标记。Excel 导出全部光束及上述明细。
当前原始接触帧缓存最多 600000 帧，并按约 64 MiB 的容量预算随段数缩小；超过预算
保留末尾帧，报告标明截断。原始帧可从本次报告导出，历史库沿用原有行为：保存报告
和回放，不保存全速原始帧。统计在缓存裁剪前完成。

自动测试覆盖就绪失效、线程内开始核查、不同长度和跨段几何、反向通过、人工结束、
停步、异常后恢复、严重异常中止、指标不足、配置/历史报告以及完整长度导出。
这些测试验证软件规则，默认接触、停步和出口阈值仍需 Windows 实机配合视频标注验证；
一维重叠遮挡不可完全恢复双脚形状或身份。

## v1.1 短接触连续性修正

短接触候选保留在记录及导出中，作为相邻步和同脚周期的统计屏障；不得删除候选后跨过它拼接距离。短接触使左右交替锚点不可靠后，后续接触只使用 A/B，后续连续有效步仍可恢复统计。正常接触的中心参考和时间计算口径不变，既有历史报告不重算；新报告算法标识为 `overground_walking_v1.1`。

## v1.2 保留中断前的停步证据

丢帧或其他连续性中断前已确认的停步候选保留，终点不超过最后可靠接触样本的结束边界。中断后的数据独立处理，不拼接不足阈值的片段，也不重复记录相同停步。新报告标识 `overground_walking_v1.2`。
