# E5：Windows 离线 process + batch40 对照

组合仅启用质量窗口更新与严格空场路径，接收输入为固定保存记录；读端解码缓存不在本组 GUI 对照中。生产源 SHA 未改，无 USB、相机、SDK 或人体采集。Qt 为 Windows PyQt5 5.15.2、offscreen、DPR 1；终点是 Qt 绘制返回，不是屏幕扫描输出。

每轮保存录像均解码 741/741 个到期 JPEG，实际预览显示约 627–632 帧；最新帧预览允许覆盖旧帧，解码负载没有省略。没有姿态推理与 SDK 负载，不等同完整现场负载。

绝对门槛：四个候选轮均 P95≤150ms、max≤250ms、排队加在途帧上界≤250；年龄增长斜率门槛也通过。年龄统计按批次／探针边界采样，不声称连续最大年龄。上界由已入队位置与上一个已完成批次位置重建，独立复核一致。

稳定改善门槛未通过：P95 配对改善中位数 0.34%，仅两对改善，未满足至少三对改善且中位数≥20%。不能宣称解决历史积压，也不能由一个保存走路输入反复回放外推长期可靠性或真人准确性。

完整原始输入、归档、报告、质量窗口、事件和时间线逐字段一致；只排除三处重新生成的 checked_monotonic_ns，并逐项核对其来自同样本的原始接收时钟。八个计分轮全部独立复核通过。

旧版 GUI 校准因 GUI 定时器遗漏录像解码负载且缺少字体目录而被拒绝，证据保留在 native_windows/E5v2_GUI。修正版本先完成两轮不计分校准，再执行 AB/BA 四对；未修改性能阈值。

本轮没有扩展到设备时钟等间隔 GUI、更多负载和人体实验：现有原记录到达节奏对照已未通过稳定改善门槛，先保留候选与否定结果，不进入生产。
