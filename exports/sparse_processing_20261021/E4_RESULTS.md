## E4：单向退役影子验证

仅标记潜在可退役区域，原算法仍完整执行。方向未知／反向、重新遮挡、待处理接触、有效性异常、缺帧和 stream 变化均在触发样本撤销标记，七组反例通过。

| 输入 | 可退役段采样数 | 全部段采样数 | 标记／撤销事件数 |
|---|---:|---:|---:|
| empty | 0 | 480000 | 0 |
| sparse | 0 | 480000 | 0 |
| cross | 65362 | 480000 | 2 |
| plateau | 0 | 480000 | 0 |
| stress | 0 | 480000 | 0 |
| field_run_20261015_02 | 0 | 195704 | 0 |
| field_walk_full_02 | 0 | 238936 | 0 |

诊断保存的是存在退役标记时整个簇提取函数的受扰动墙钟上界，不是退役段独占 CPU。该上界不能证明达到消费者 CPU 5% 的推进门槛，因此本轮不引入实际退役；可退役时间占比也不换算为收益。
