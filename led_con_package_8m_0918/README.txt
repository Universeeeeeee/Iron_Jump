768-LED 状态可视化程序（八米版, Windows 64 位）
==================================================

由三米版 (led_con_package_3m) 移植：8 段 LED 阵列 × 96 LED = 768 状态位。
完整的软件接口、操作流程、日志字段和故障排查说明见：
软件接口与操作说明.md

运行条件
--------
1. Windows 10/11 64 位。
2. 已安装 64 位 Python 3.11 或 3.12，并在安装 Python 时勾选
   “Add Python to PATH”。
3. 已安装采集设备对应的 Windows USB 驱动。
4. 首次运行需要联网下载约数百 MB 的 Python/Qt 依赖。

使用方法
--------
1. 将 ZIP 完整解压，不能直接在压缩包预览窗口中运行。
2. 双击 start_led_con.bat。
3. 首次运行会在当前目录创建 .venv 并自动安装依赖，请等待完成。
4. 程序窗口打开后连接设备，点击“开始测试”。

默认硬件参数
------------
VID: 0x04B4
PID: 0x1004
DLL: hardware\CyUsbInterface.dll（64 位）

如果设备参数不同，可以在启动前设置以下环境变量：
DAYU_VID、DAYU_PID、DAYU_DLL、DAYU_TIMEOUT、DAYU_CHUNK。

八米版数据格式（2026-09-18）
---------------------------
每帧 LED 数据 96 字节 = 8 节点 × 12 字节 = 768 状态位。
支持两种分包形式：
- 单包：packNum=1，一包 96 字节，完整协议包 102+12=114 字节；
- 八分包：packNum=8，每包恰好 12 字节，每包完整协议包 30 字节。
仅完整 96 字节的有效帧更新界面；长度不符、分包编号/数量异常、
冲突重复分包、整帧 96 字节全 0（768 灯全灭）的数据不显示、不导出。
异常帧不会清空上一帧；单段全灭和局部遮挡保留。CRC 或帧尾校验
失败的数据仍由协议层丢弃。不完整分包超过 1 秒后不再参与拼接。

八米段顺序配置
--------------
默认物理线序为恒等映射：线上第 1~8 组依次为 1m、2m、3m、4m、
5m、6m、7m、8m。该线序经实机验证确认，已内置为默认值，无需
任何设置。
（早期假设的“2m..8m、末组 1m”线序经实测发现整体右移一位，
即面板 2m 显示实际 1m、面板 1m 显示实际 8m，故修正为恒等线序。）
如实际线序与此不符，启动前设置环境变量 DAYU_SEGMENT_ORDER 覆盖，
例如线序为 [2m,3m,1m,4m,5m,6m,7m,8m] 时：
    set DAYU_SEGMENT_ORDER=2,3,1,4,5,6,7,8
（逗号分隔的 8 个数，第 i 个数 = 线上第 i 组对应的米段编号，
必须是 1..8 的排列。）程序重启后生效。

坏灯位置校验
------------
3m 版默认启用的“2m 首灯永久损坏”校验是旧套件特有的，8m 版默认
关闭。现场如确认固定坏灯，可设置 DAYU_REQUIRED_DARK_BITS 指定
必须保持熄灭的线序位索引（0..767，逗号分隔），程序重启后生效。

界面说明
--------
右侧为 2 列 × 4 行共 8 个 8×12 面板：绿色表示 LED 亮/未遮挡，
灰色表示 LED 灭/遮挡。结束测试时可选择将采集数据保存为 Excel
（769 列 = 时间戳 + 8×96）；文件位于包内 data 目录。

频闪过滤与 1ms 数据周期
-----------------------
与 3m 版一致：新状态默认连续至少 3 帧相同且持续至少 10 毫秒才
用于显示、日志和导出（DAYU_FRAME_CONFIRM_MS 可调，设 0 关闭
时间确认）；USB 超时默认 1ms（DAYU_TIMEOUT 可覆盖），接收线程
按连续字节流逐帧解析粘包，不按墙钟硬切帧。

故障排查
--------
- 提示 Python was not found：安装 python.org 提供的 64 位 Python。
- Python 已安装但 py 命令不存在：重新安装并启用 Python Launcher 和 PATH。
- DLL 加载失败：确认系统和 Python 均为 64 位，并安装设备驱动及 DLL 所需
  的 Microsoft Visual C++ 运行库。
- 设备无法连接：检查驱动、USB 连接以及 VID/PID 是否与设备一致。
- 面板数据与米段不对应：确认 DAYU_SEGMENT_ORDER 与实际线序一致。
