plan01在运行前绑定源码、依赖、输入及分析判据，固定4对8窗，顺序AB、BA、AB、BA。无额外A/A、无中途延长或替换。任何基础设施/语义/真实SDK失败即停止后续窗，全部失败与未执行记录保留。原版完整报告/quality/runtime/raw与独立基准逐窗核验；SDK独立PID、实际加载精确DLL、原停止/关闭、模型最终收尾和进程退出必须通过。

严重原版门槛：至少3/4原版窗同时满足观测deque峰值下界>=1000帧、计划接触至绘制最大延迟>=1000ms。实验桥每窗必须deque连续峰值上界<=250帧、计划接触至绘制最大延迟<=250ms；每个严重配对的延迟降低至少50%。所有窗正式输入最大投递迟到<=100ms。队列沿用原保守边界，不用平均1000FPS冒充实时性。
