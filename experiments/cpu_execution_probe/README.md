# 独立原生执行速度基线：有测量值，尚无慢/快因果证据

继 `3cd966f` 的四个慢态窗口，本次只执行一个不到一秒原生活跃计算的进程和只读环境查询。没有新增 Walk/GUI 回放，没有改变电源策略、亲和性或正式文件，也没有安装驱动。目的是获得独立于 PDH 的固定指令执行速度基线，不扩展栈观测工具。

## 固定工作与交付校验

`plan01.json` 在运行前绑定 Python 源码和 72 字节 x64 指令哈希，固定六次循环规模：8M、32M、32M、8M、8M、32M。原生函数只改 Windows x64 易失寄存器 RCX/RAX：清零 RAX；每轮 16 次依赖的 `add rax,1`；RCX 减一并循环；返回 RAX。跳转目标核对为首个 add，循环次数均大于零。

函数仅存在于本进程：先分配可读写内存、复制固定指令，再改为只读可执行，刷新指令缓存，最后释放；未保留 RWX 内存或注入其他进程。1、2、17 次正控制分别返回 16、32、272，六个正式返回值均等于预定加法次数。

| 顺序 | 依赖加法次数 | 墙钟 ms | 十亿次加法/墙钟秒 | CPU 端点 |
|---|---:|---:|---:|---|
| 1 | 128M | 54.003 | 2.3702 | 2→2 |
| 2 | 512M | 217.012 | 2.3593 | 2→2 |
| 3 | 512M | 215.486 | 2.3760 | 2→6 |
| 4 | 128M | 53.673 | 2.3848 | 6→6 |
| 5 | 128M | 53.715 | 2.3829 | 6→6 |
| 6 | 512M | 214.762 | 2.3840 | 6→6 |

三对四倍工作量的墙钟比为 **4.0185、4.0148、3.9982**，在冻结的 3.2–4.8 范围内；输出与内存释放核验通过。所有窗口保留，其中一个 CPU 端点改变。端点相同也不能证明中间没有迁移。短窗口线程 CPU 记账粒度较粗，出现 CPU 时间超过墙钟，因此不得做等待份额相减。

**2.359–2.385 是实测依赖加法吞吐，不是 GHz。** 没有通过该机器的真实硬件周期/指令事件认证“每个 add 恒为一周期”；分支、流水线、调度和虚拟化等因素仍存在。不能把它直接与标称 2.4GHz 相等，更不能把历史约 1.7 倍运行差异直接解释为 2.4→4.1GHz。六次循环是一次当前状态基线，不是六次慢/快独立实验，也不是现场修复证据。

## 只读环境结果

- 系统为 LENOVO 81T0，报告 `HypervisorPresent=true`；它不等于证明应用在客户虚拟机内，也不证明计数器错误。
- 有效电源 overlay GUID 为 `ded574b5-45a0-4f42-8737-46345c09c238`，保留原值，不由它推断实际 CPU 交付。
- 当前 AC/DC `PROCFREQMAX` 均为 0，未发现这个设置显式限制最大 MHz。前轮记录最大处理器状态 100%、提升模式 2；策略允许不代表实际执行。
- `intelppm` 驱动 Running / OK，Start=3。未发现驱动被禁用这一直接解释。
- 新建只读 SSH Python 进程为 Normal 优先级（32）；进程和线程 PowerThrottling 查询成功，control/state masks 均为 0。它们不是已结束的历史目标线程记录，不能据此否定历史自动 QoS。
- 过去一天的 Kernel-Processor-Power 37 查询没有返回事件；BIOS 设置与相关监控进程查询也没有返回条目。查询空集不证明没有固件限速，也不证明 BIOS 已开启睿频。

## 决策与剩余边界

现在已有一个能核对实际完成工作的独立执行速度基线，但仍没有证据说明究竟哪个系统设置导致慢态。**停止继续增加同类只读快照或重复当前状态的基准。** 不把“没有查到限制”解释成“硬件无问题”，也不未经交付验证就改动正式算法。

只选择下一项控制：**实验进程默认系统管理 vs 显式退出执行速度节流**，即仅改变 `PROCESS_POWER_THROTTLING_EXECUTION_SPEED` 的控制归属，候选 ControlMask=1、StateMask=0。当前 0/0 并不证明发生了动态节流，所以它只是待证伪假设。进程退出即结束，不改全局电源方案、BIOS 或正式程序。getter 只检查配置交付，必须同时看原生吞吐和完整原工作。判据见 `next_candidate01.json`；本阶段尚未执行该控制。

根因目标仍未完成。历史完整性、扰动失败及全部现场窗口不变；原 GUI 1000Hz 下的 pending/contact→paint 修复仍需证明。
