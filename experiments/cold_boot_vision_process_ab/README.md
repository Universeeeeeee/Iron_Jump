# 四次重启分离的首窗视觉进程对照

本实验不需要人体、USB或现场走路。四次Windows重启后各运行一个保存输入GUI首窗，顺序为进程、原版、原版、进程；每次登录后等待开机满120秒，要求20分钟内、交互Session、BelowNormal和交流供电。前三窗成功后自动请求下一次重启；任一失败立即停止，不再重启。

只有两个原版首窗都达到队列下界≥1000且计划接触至绘制≥1000ms，同时两个进程首窗都达到队列上界≤250且延迟≤250ms，才允许进入真实单USB Walk现场验证。任一合格进程首窗仍严重则否定该候选；原版冷启动未复现则证据不足。重启是复合状态重置，成功也不能命名为频率、缓存、电源或温度机制。
