## 固定预算与共同路径

先4个同进程原版A/A窗口，再4对original/isolated，以AB、BA、AB、BA顺序，共12个新进程窗口。每窗使用相同保存Walk原始输入、媒体、原ExecutionView/renderer、原真实模型、原SDK Python serve/runtime及共同模拟原生硬件后端。复用已验证的 `session_local_baseline/gui.run` 函数，不为候选删绘制或视觉任务。

原版保留原Controller/测量QThread在GUI进程，直接转发信号，不加测量IPC。隔离版使用原测量会话actor、有界输出/接收和确认状态，不改变原NumPy、滤波、Processor、原信号DirectConnection和原绘图。比较包含必要IPC和原生调度随进程边界变化的整体效果，**不是独占GIL的单一机制百分比**。

任何基础设施、源码、原始数据/完整报告/质量状态、资源或上下文失败都停止后续窗口，保存PID、锁与失败；观察超时不能作为目标已经停止的证明。若原版没有至少3/4严重复现，也不会追加轮次、替换病例或降低门槛。没有人体、USB、Run或正式程序修改。

## 接触阶段上下文

复用既有只读 `gui_qos_candidate/runtime_context.snapshot`，没有新增周期采样器。GUI、模型和消费者各在dense_start(59904)及mixed_start(65904)两个逻辑边界后读一次，共6次；消费者按实际批完成样本触发，GUI/模型按已验证的arm后source原点和原录制偏移触发，均先执行原函数。观察器错误保留为验收失败，不能跳过原绘制或原消费。

记录实际PID/TID、Session、进程优先级、进程/线程power-throttle配置和前台PID。每次读上限仍为原50ms；所有角色须实际BelowNormal(16384)，不静默修改优先级/QoS。配对要求相同策略及“前台是本窗GUI”的模式。消费者的foreground_self在进程化后结构性不同，原始值保留，不能错误要求两侧消费者都为前台进程，也不由此前台差异归因GIL。

两个逻辑阶段点并非连续调度覆盖，也不保证各案例在相同物理时刻读取。原来ordinal1/100的快照可能都发生在接触前，本阶段不将其冒充接触态证据。

## A/A与判定的适用范围

4个A/A用于描述相同入口的自然波动，计算log标准差与近似t区间；四个连续窗口的独立/平稳假设未证实。**它不是OFF/ON工具扰动校准，也不关闭旧3%/1%失败**。本阶段不计算GIL等待占比、锁持有时间或各函数CPU贡献。

四对症状决定直接复用原 `decision.decide`，保持至少3个严重原版（观测deque≥1000、receipt接触绘制≥1000ms）、每对改善、计划接触绘制几何改善≥20%、每个候选最大计划延迟≤250ms、队列连续上界≤250帧、所有输入迟发≤150ms。动态视频、推理、SDK和绘图工作全部保留为结果，不事后配平。

即使该受观测的整体原型症状门槛通过，旧扰动/原生栈失败、真实人体USB、正式集成与根因责任函数仍未获资格。若不通过，按原因收敛，不追加同计划窗口。
