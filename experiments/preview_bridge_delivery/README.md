# 真实模型更新下的预览桥交付安全窗口

承接 ca80f4b，遵循相机预览 GIL 最小因果实验路线，不扩展进程隔离。本轮只有一个预先冻结的安全窗口，没有性能 A/B或严重积压收益判断。

原SessionController/QThread、完整光栅保存输入、原真实视觉模型、latest-only策略、GUI更新/绘图及CameraControlService协议保持。仅在本实验进程安装由AST核验的AnnotationCanvas.paintEvent派生函数，替换第一条QLabel基类调用；其余骨架/标注语句相同，退出时恢复原方法。原正式文件、NumPy、滤波、Processor、缩放、预热、线程配置和已有绘图候选未改。

重要范围：沿用现有安全夹具的fake_sdk原生端。CameraControlService协议和独立SDK PID存在，但不是实际OBSBOT原生服务负载，不能将本轮升级为完整真实SDK资格。没有真实相机/光栅访问、人体、USB或Run。

## 已交付结果

- 632次实验桥预览绘制，626次有骨架；同一GUI线程，调用前后对象/event有效且Cpp指针不变，没有记录到嵌套绘制或桥异常。
- 402次真实模型调用，794个保存视频帧，原模型/GUI审计未记录回调错误。
- 33,188帧（含预检）的完整原始字段、报告、quality/runtime状态与独立基准一致。
- DPR1.25控件、DPR1图像；绘制语句AST尾部相同。动态视频逐像素历史未在本窗口做跨模式比较，完整合成像素验证仍以前一阶段为限。
- 方法恢复、GUI/测量线程及模型最终关闭通过。原应用返回时模型未确认关闭的状态保留，尾部最终确认不改写前一边界。
- 子进程Popen和父控制器保留句柄的Win32/.NET均确认退出码0，已完成任务移除，5个锁保留。

运行期间的有效性断言与计数器属于安全观察，会增加开销，不是正式性能A/B候选的共同测量层。一次窗口没有发现错误不证明任意重入回调、关闭时序或对象寿命都安全。此前控件合成故障注入仍是异常传播的有限证据，不冒充本窗口实际故障。
